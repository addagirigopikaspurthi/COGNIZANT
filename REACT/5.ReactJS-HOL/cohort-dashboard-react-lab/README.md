# Cohort Dashboard

React hands-on lab for styling components with a CSS Module and inline styles.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lab Requirements Covered

- `CohortDetails.module.css` contains the `box` class.
- The `box` class is applied using `className`.
- The `dt` tag selector sets `font-weight: 500`.
- The `h3` color is applied with inline style:
  - `green` for `Ongoing`
  - `blue` for all other statuses
